# DocumentManager

一个基于 SwiftUI 开发的轻量级 macOS 文件管理器。

当前支持目录浏览、文件夹大小显示、排序，以及带安全保护的编辑模式。

## 功能

- 浏览 macOS 本地文件夹
- 显示文件类型、大小和修改时间
- 异步计算文件夹大小
- 支持按名称、类型、大小、修改时间排序
- 支持显示或隐藏隐藏文件
- 默认只读模式
- 支持带自动超时保护的编辑模式
- 支持重命名文件
- 支持将文件移到废纸篓
- 编辑模式下支持多选后批量删除

## 安全机制

- 使用 App Sandbox
- 只能访问用户主动选择并授权的目录
- 必须手动开启编辑模式后才允许写操作
- 编辑模式会在短时间后自动关闭
- 删除操作默认移到废纸篓，不会直接永久删除

## 运行环境

- macOS 14 及以上
- Xcode 15 及以上

## 运行方式

1. 使用 Xcode 打开 `DocumentManager.xcodeproj`
2. 选择 `DocumentManager` target
3. 编译并运行
4. 点击“选择文件夹”授权要访问的目录

## 说明

- 文件夹大小会在后台异步计算，大目录可能需要一点时间更新
- 写操作仅对用户明确授权的目录生效
